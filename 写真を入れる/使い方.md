# ここに写真や動画を入れてください

1. このフォルダを開いた状態で、右上の **Add file → Upload files**
2. 投稿したい写真（1枚でも、10枚まででも）をドラッグして、下の緑のボタン **Commit changes**
3. 数分で、AIが投稿文を作って次の投稿日（月・水・金 21:00）に予約します
4. 「【予約しました】」というメールが届きます。文章を確認してください

- **一度に入れた写真は、1つの投稿**になります（2枚以上ならスワイプで見る投稿）
- **動画は1本ずつ**、インスタはリール、Threadsは動画の投稿になります
- 別々の投稿にしたいときは、1回ずつ分けて入れてください
- 写真の並び順は、ファイル名の順です
